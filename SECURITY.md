# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.5.2   | :white_check_mark: |
| < 0.5.0 | :x:                |

## Reporting Vulnerabilities

Please report security issues directly to Glass Line Studio at `security@glasslinestudio.com`.
Do not open public GitHub issues for security vulnerabilities.
